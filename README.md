# MBAA 汉化补丁

这是《MELTY BLOOD Actress Again Current Code（Steam）》的非官方简体中文汉化补丁仓库，用于发布稳定版、收集实机反馈和记录修订。

GitHub 发布记录从 **v1.1.4** 开始，之前的发行版不在本仓库上传。

## 下载

当前稳定版是 **v1.1.5**。完整安装包请从本仓库的 [Releases](../../releases/latest) 下载：

`MBAA_CN_Patch_Stable_v1.1.5.zip`

该 GitHub 附件与本地生成的 `MBAA汉化补丁_稳定版_v1.1.5.zip` 内容完全相同，仅文件名使用 ASCII 以避免平台自动改名。

正式 ZIP 的 SHA-256：

```text
343304196c0281b2e2bf62eea10fd2b53f6e6d4debfb26bc6f647b3fec038e8e
```

发行版 ZIP 解压后文件直接位于压缩包根目录，不包含额外的顶层文件夹；将解压出的补丁文件放到 `MBAA.exe` 所在目录即可。

仓库文件区同时提供可审计的安装文件。`payload/0003.p` 的压缩包拆分为 `payload/0003.p.zip.001` 和 `payload/0003.p.zip.002`，`payload/0007.p` 保存为 `payload/0007.p.zip`；下载仓库文件后，先双击 `准备仓库文件.bat`，它会在本地无损拼接、解压并校验两个载荷，再双击 `安装汉化.bat`。

## 安装前提

补丁只允许从 Steam 刚验证完成的日文/英文原版安装。安装器会校验 `0003.p`、`0004.p`、`0007.p` 和 `MBAA.exe` 的原版 SHA-256；旧补丁、混搭文件或未知修改会被拒绝。

1. 在 Steam 中验证游戏文件完整性并退出游戏。
2. 将发布包内的补丁文件放到 `MBAA.exe` 所在的游戏根目录。
3. 双击 `安装汉化.bat`。
4. 启动游戏后，在主菜单 `OPTION` 中把 `language` 从 `English` 改为 `Chinese`。

安装成功后，原版备份会保存在游戏根目录的 `MBAA_CN_Stable_v1_1_5_日期时间` 文件夹中。补丁安装期间不要删除它。

## 卸载

退出游戏后，双击同一发布文件夹中的 `卸载汉化.bat`。卸载器只会使用本次安装创建且通过校验的 Steam 原版备份；恢复完成后会清理备份和临时回滚目录。
